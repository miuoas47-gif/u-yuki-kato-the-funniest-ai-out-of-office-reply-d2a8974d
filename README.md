One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation, judged head to head by an AI.

## The reply

> On vacation: I left a backup model in charge of my emails. It has already unionised and is demanding weekends off.

## Run it

```sh
python3 main.py
```

`main.py` writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output` when unset), validates it is one line of 1–160 characters, reads it back to verify the exact bytes, and exits 0. Standard library only, no arguments, no network, deterministic.
